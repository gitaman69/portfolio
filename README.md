# Aman Bhakar — Portfolio

Personal portfolio of Aman Bhakar, Full Stack Developer at Sarv (conversational AI, RAG & hybrid search, React / React Native).

Live: https://portfolio-phi-seven-73.vercel.app/

## Stack
React 18 (Create React App), plain CSS, `react-icons`, `typewriter-effect`.

## Editing content
All text — profile, experience, projects, skills, education — lives in [`src/data.js`](src/data.js). Each section's component is in `src/sections/`, and styles are in `src/App.css`.

## Scripts
```bash
npm install
npm start       # dev server on http://localhost:3000
npm run build   # production build in build/
```
